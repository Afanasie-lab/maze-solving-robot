This zip includes: 
- our arduino code which contains line-following functions and controls the robot through WiFi, in the .ino file in this folder
- our GUI which sends commands to the robot and displays data and a map, in the .java file in this folder

In order to run the code, make sure you have:
- the Arduino IDE with the WiFi 101 library installed
- the Java JDK installed
- the Feather M0 WiFi robot car

Steps to control the car with our code:
1. Power up the robot car.
2. Connect your computer to the board with the USB connection
3. Open our .ino file in the Arduino IDE
4. Select the correct board in the Arduino IDE
5. Send the .ino file to the board
6. Unplug the USB connection, and connect power back to the Arduino.
7. Wail around 10 seconds and connect your computer to the robot's WiFi.
8. Run our .java file
9. Use our GUI to control the robot and see its path and its live data
